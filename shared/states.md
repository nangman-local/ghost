# 상태 정의 (단일 진실의 원천)

Android · Desktop · Server가 공유하는 상태 이름. **이 파일의 문자열을 그대로 쓴다.**
변경 시 팀 공유 채널에 공지하고, 세 클라이언트를 동시에 갱신한다.

## 세션 상태 `state`

| 값 | 의미 |
| --- | --- |
| `WAITING` | 할 일 미시작 / 대기 |
| `FOCUS` | 할 일 관련 행동 중 |
| `DISTRACT` | 딴짓 중 |

전이: `WAITING → FOCUS` (할 일 시작) · `FOCUS ↔ DISTRACT` (판정 누적) · `* → WAITING` (세션 종료)

## 개입 단계 `interventionLevel`

| 값 | 이름 | 행동 |
| --- | --- | --- |
| `0` | 없음 | 캐릭터 평상시 상태 |
| `1` | 환기 | 캐릭터 애니메이션 변화, 시선 끌기 |
| `2` | 복귀 제안 | 말풍선으로 현재 할 일 제시 |
| `3` | 화면 개입 | 콘텐츠 일부 가리기 (가린 영역만 터치 차단) |

4단계(강제 잠금)는 MVP 범위에서 제외한다.

**3단계는 규칙으로 확정됐거나 AI confidence가 높을 때만 허용한다.** 오탐이 미탐보다 훨씬 치명적이다.

## 활성 기기 `activeDevice`

`PC` · `ANDROID`

## 캐릭터 상태 `characterState`

Rive 애니메이션 상태 이름. 캐릭터 담당이 `.riv`에 동일한 이름으로 정의한다.

| 값 | 대응 |
| --- | --- |
| `IDLE` | `state=FOCUS` 또는 `WAITING`, `interventionLevel=0` |
| `ALERT` | `interventionLevel=1` |
| `TALK` | `interventionLevel=2` |
| `BLOCK` | `interventionLevel=3` |

## 판정 라벨 `label`

`/judge` 응답과 로컬 규칙 판단이 공유한다.

`FOCUS` · `DISTRACT` · `AMBIGUOUS`

`AMBIGUOUS`는 개입하지 않는다. 캐릭터가 사용자에게 직접 물어본다.

## 개입 전이 규칙 (임시값)

> ⚠️ **이 표의 숫자는 임시값이다.** 예소팀 7명이 2026-09-24부터 도그푸딩하며 체감을 보고 조정한다.
> 조정 결과는 #10 에서 확정하고 이 표를 갱신한 뒤 팀 공유 채널에 공지한다.
> **Android와 PC가 같은 값을 쓴다.** 한쪽만 바꾸지 않는다.

| 항목 | 임시값 | 근거 |
| --- | --- | --- |
| `minHoldSeconds` | 20초 | `distract-rules.json` 과 동일. 이 시간 이상 유지돼야 판정한다 |
| `FOCUS → DISTRACT` | 딴짓 누적 60초 | 짧은 이탈(카톡 확인)과 구분 |
| 레벨 0 → 1 (환기) | 딴짓 누적 10분 | 구현방안 v1.0 §5-5 |
| 레벨 1 → 2 (복귀 제안) | 딴짓 누적 15분 | 구현방안 v1.0 §5-5 |
| 레벨 2 → 3 (화면 개입) | 딴짓 누적 20분 | 구현방안 v1.0 §5-5. **MVP 미구현(#22)** |
| 복귀 시 강등 | 즉시 0 으로 초기화 | 돌아왔는데 개입이 남아 있으면 안 된다 |
| 복귀 판정 유예 | 30초 | 이 시간 이상 `FOCUS` 여야 누적을 리셋한다 |

### 누적 규칙

- **누적은 연속이 아니라 세션 단위 합계다.** 딴짓 → 잠깐 복귀 → 딴짓 을 반복해도 누적은 이어진다.
  (쇼츠를 보다 잠깐 할 일 앱을 켰다 다시 돌아오는 패턴에서 개입을 회피하지 못하게 한다.)
- **복귀 유예(30초) 이상 `FOCUS` 상태가 유지되면 누적을 0 으로 리셋한다.** 진짜 복귀로 본다.
- `AMBIGUOUS` 는 **누적하지 않는다.** 판단하지 않고, 개입하지도 않는다.
- 레벨은 **한 번에 한 단계씩만** 올라간다. 20분을 한 번에 채워도 0 → 1 → 2 순서를 밟는다.
- 레벨은 **내려가지 않는다** (복귀로 0 이 되는 경우를 제외하고). 같은 딴짓 구간에서 레벨이 오르내리면 사용자가 혼란스럽다.

### 개입 무시 (`INTERVENTION_DISMISSED`)

사용자가 스누즈(#64)를 고르면 그 시간 동안 개입을 멈춘다. 스누즈가 끝나면 **직전 레벨을 유지한 채** 재개한다
(레벨을 0 으로 되돌리면 스누즈를 반복해 개입을 무한히 회피할 수 있다).
