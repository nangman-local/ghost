# GHOST

> 딴짓하고 있는 순간, 먼저 찾아와 흐름을 끊어주는 집중 동반자

사용자가 해야 할 일을 두고 다른 행동에 빠졌을 때 이를 감지하고, 플로팅 캐릭터가 먼저 개입해 다시 할 일로 돌아오도록 돕는 생산성 서비스입니다.

경희대학교 2026-2학기 팀 프로젝트 (7인).

---

## 핵심 컨셉

기존 생산성 앱은 **사용자가 집중 모드를 먼저 켜야** 작동합니다. 하지만 도움이 가장 필요한 순간은 이미 유튜브·릴스·게임에 빠져 시간 감각을 잃은 때이고, 그때 사용자는 생산성 앱을 다시 열 생각 자체를 하지 못합니다.

GHOST는 반대로 갑니다. **집중이 무너지는 순간 서비스가 사용자를 찾아갑니다.**

```
할 일 인식 → 사용 행동 감지 → 딴짓 판단 → 지속 시간 확인 → 캐릭터 개입 → 복귀 유도
```

**핵심 가설:** 딴짓 중인 순간 캐릭터가 먼저 개입하면, 사용자가 원래 할 일로 더 잘 복귀한다.

차별성은 앱 차단 자체가 아니라 **개입 시점**에 있습니다. "집중하게 만드는 것"보다 **"딴짓에서 빠져나오게 만드는 것"** 이 목표입니다.

---

## 개입 단계

딴짓을 금지하지 않습니다. 잠깐의 휴식이나 메시지 확인은 방해하지 않고, 일정 시간 이상 지속될 때만 **단계적으로** 개입합니다.

| 단계 | 캐릭터 행동 | 예시 |
| --- | --- | --- |
| 0 · 평상시 | 화면 구석에서 대기 | |
| 1 · 환기 | 시선 끌기, 시간 알림 | "유튜브 본 지 10분 됐어" |
| 2 · 복귀 제안 | 말풍선으로 작은 행동 제안 | "딱 2분만 시작해볼래?" |
| 3 · 화면 개입 | 콘텐츠 일부 가리기 | 캐릭터가 화면 중앙으로 이동 |

4단계(앱 강제 잠금)는 MVP 범위에서 제외합니다. 클릭을 완전히 막거나 앱을 강제 종료하지 않습니다.

**캐릭터는 감시자가 아니라 동반자입니다.** 혼내는 존재가 아니라 같이 집중하고 같이 돌아오는 존재로 설계합니다.

## 저장소 구조

모노레포입니다. 공통 정의는 [`shared/`](./shared/) 가 **단일 진실의 원천**입니다.

```
ghost/
├── AGENTS.md      팀 공통 헌법 — 작업 시작 전 필독
├── CONTRIBUTING.md 브랜치·커밋·PR 규칙
├── shared/        상태 이름 · API 스키마 · 규칙 사전 · 이벤트 정의
├── android/       Kotlin + Jetpack Compose        (Spike 1~3 완료)
├── desktop/       Electron (Windows)              (Spike 4 완료)
├── server/        Spring Boot + PostgreSQL        (스캐폴드)
└── web/           랜딩 · 지표 대시보드            (스캐폴드)
```

| 폴더 | 문서 | 실행 방법 |
| --- | --- | --- |
| [`android/`](./android/) | [AGENTS.md](./android/AGENTS.md) · [README.md](./android/README.md) | `./gradlew :app:assembleDebug` |
| [`desktop/`](./desktop/) | [AGENTS.md](./desktop/AGENTS.md) · [README.md](./desktop/README.md) | `npm install && npm start` |
| [`server/`](./server/) | [AGENTS.md](./server/AGENTS.md) · [README.md](./server/README.md) | 미구현 |

## 아키텍처

```
[Android 앱]                          [Windows PC 앱 (Electron)]
 - 현재 앱 / 도메인 / 제목 감지         - 활성 창 앱명 / 창 제목 감지
 - 플로팅 캐릭터 (Rive)                - 투명 오버레이 캐릭터 (Rive)
 - 개입 상태머신                       - 개입 상태머신
 - 캘린더 읽기
        │ REST (하트비트·이벤트)             │ WebSocket
        └──────────────┬─────────────────┘
                       ▼
                    [서버]
   - 인증 / 할 일 / 세션 (진실의 원천)
   - /judge : 규칙 사전 + LLM 판단 + 캐시
   - 이벤트 로그, 지표 집계
                       │
                       ▼
                  [경량 LLM API]
```

**딴짓 판단은 서버 `/judge` 하나로 통일합니다.** 기기 로컬에서는 [`shared/distract-rules.json`](./shared/distract-rules.json) 규칙 사전으로 1차 분류하고, 모호한 경우에만 서버를 호출합니다. **AI가 실패해도 규칙만으로 동작해야 합니다.**

상세 원칙은 [`AGENTS.md`](./AGENTS.md), 계약은 [`shared/api-schema.md`](./shared/api-schema.md)를 보세요.

## 프라이버시

사용자를 감시하는 서비스가 아닙니다.

- **서버로는 도메인과 제목만 보냅니다.** URL 쿼리스트링과 화면 텍스트는 보내지 않습니다.
- 화면 캡처 + 이미지 AI 분석은 사용하지 않습니다.
- 설정의 **"캐릭터가 본 것" 로그**에서 무엇이 감지·전송됐는지 사용자가 직접 확인할 수 있습니다.
- **LLM API 키는 서버에만 둡니다.** 클라이언트 코드에 넣지 않습니다.

## 성공지표

| 지표 | 정의 | 계산 |
| --- | --- | --- |
| **복귀율** | 개입 후 할 일로 돌아온 비율 (핵심 가설) | `RETURNED_TO_TASK / INTERVENTION_SHOWN` |
| **딴짓 시간 감소율** | 평균 연속 딴짓 시간 변화 | 개입 off 3~4일 → on 3~4일 비교 |
| **오탐율** | 집중 중인데 딴짓으로 오판한 비율 | `USER_CORRECTED(FOCUS) / DISTRACT_STARTED` |

**오탐이 미탐보다 훨씬 치명적입니다.** 집중 중에 캐릭터가 방해하면 사용자는 앱을 지웁니다.

이벤트 정의는 [`shared/events.md`](./shared/events.md) 참고.

## 기여하기

**작업 시작 전 [`AGENTS.md`](./AGENTS.md)를 반드시 읽으세요.** 브랜치·커밋·PR 규칙은 [`CONTRIBUTING.md`](./CONTRIBUTING.md)에 있습니다.

```
develop 에서 브랜치 생성 → 작업 → 해당 폴더 AGENTS.md 갱신 → develop 으로 PR
```

코드를 바꿨으면 **해당 폴더의 `AGENTS.md`도 갱신해야 합니다.** CI가 검사하며, 갱신이 없으면 PR이 실패합니다.
