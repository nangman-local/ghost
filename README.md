# GHOST

> 딴짓하고 있는 순간, 먼저 찾아와 흐름을 끊어주는 집중 동반자

해야 할 일을 두고 다른 행동에 빠졌을 때 이를 감지하고, 화면 위 플로팅 캐릭터가 먼저 개입해 원래 할 일로 돌아오도록 돕는 생산성 서비스입니다.

## 왜 만드나

기존 생산성 앱은 **사용자가 집중 모드를 먼저 켜야** 작동합니다. 하지만 도움이 가장 필요한 순간은 이미 영상이나 SNS에 빠져 시간 감각을 잃은 때이고, 그때 사용자는 생산성 앱을 다시 열 생각 자체를 하지 못합니다.

GHOST는 반대로 갑니다. **집중이 무너지는 순간 서비스가 사용자를 찾아갑니다.**

```
할 일 인식 → 사용 행동 감지 → 딴짓 판단 → 지속 시간 확인 → 캐릭터 개입 → 복귀 유도
```

차별성은 앱 차단 자체가 아니라 **개입 시점**에 있습니다. "집중하게 만드는 것"보다 **"딴짓에서 빠져나오게 만드는 것"** 이 목표입니다.

## 어떻게 동작하나

현재 할 일과 실제 사용 행동을 비교해 딴짓 여부를 판단하고, 일정 시간 이상 지속될 때만 **단계적으로** 개입합니다. 잠깐의 휴식이나 메시지 확인은 방해하지 않습니다.

| 단계 | 캐릭터 행동 | 예시 |
| --- | --- | --- |
| 0 · 평상시 | 화면 구석에서 대기 | |
| 1 · 환기 | 시선 끌기, 경과 시간 알림 | "유튜브 본 지 10분 됐어" |
| 2 · 복귀 제안 | 말풍선으로 작은 행동 제안 | "딱 2분만 시작해볼래?" |
| 3 · 화면 개입 | 콘텐츠 일부 가리기 | 캐릭터가 화면 중앙으로 이동 |

클릭을 완전히 막거나 앱을 강제 종료하지 않습니다. **캐릭터는 감시자가 아니라 동반자**로 설계합니다.

## 구성

모노레포입니다. 공통 정의는 [`shared/`](./shared/) 가 단일 진실의 원천입니다.

```
ghost/
├── shared/     상태 이름 · API 스키마 · 규칙 사전 · 이벤트 정의
├── android/    Kotlin + Jetpack Compose
├── desktop/    Electron (Windows)
├── server/     Spring Boot + PostgreSQL
└── web/        랜딩 · 지표 대시보드
```

| 폴더 | 역할 | 상태 |
| --- | --- | --- |
| [`android/`](./android/) | 앱 감지, 플로팅 캐릭터, 개입 상태머신 | 기술 검증 완료 |
| [`desktop/`](./desktop/) | 활성 창 감지, 투명 오버레이 캐릭터 | 기술 검증 완료 |
| [`server/`](./server/) | 세션 동기화, 딴짓 판단, 지표 집계 | 준비 중 |
| [`web/`](./web/) | 랜딩 페이지, 지표 대시보드 | 준비 중 |

각 폴더의 `README.md`에 실행 방법이, `AGENTS.md`에 개발 규칙이 있습니다.

## 아키텍처

```
[Android]                         [Windows PC (Electron)]
 앱 / 도메인 / 제목 감지            활성 창 이름 / 제목 감지
 플로팅 캐릭터                     투명 오버레이 캐릭터
 개입 상태머신                     개입 상태머신
        │ REST (하트비트·이벤트)          │ WebSocket
        └─────────────┬────────────────┘
                      ▼
                   [서버]
   세션 (진실의 원천) · 딴짓 판단 · 지표 집계
                      │
                      ▼
                 [경량 LLM API]
```

**딴짓 판단은 서버 `/judge` 하나로 통일합니다.** 기기에서는 규칙 사전으로 1차 분류하고, 모호한 경우에만 서버를 호출합니다. **AI가 실패해도 규칙만으로 동작합니다.**

## 프라이버시

사용자를 감시하는 서비스가 아닙니다.

- **서버로는 도메인과 제목만 전송합니다.** URL 쿼리스트링과 화면 텍스트는 보내지 않습니다.
- 화면 캡처나 이미지 분석을 사용하지 않습니다.
- 설정의 **"캐릭터가 본 것" 로그**에서 무엇이 감지·전송됐는지 직접 확인할 수 있습니다.
- 짧은 행동은 딴짓으로 누적하지 않으며, 사용자가 "이건 할 일 관련이야"로 교정할 수 있습니다.
